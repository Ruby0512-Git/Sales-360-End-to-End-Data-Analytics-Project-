# Sales-360-End-to-End-Data-Analytics-Project-
End to End sales 360 Data Analytics project using Excel, SQL and Power BI to clean ,analyze, and visualize sales data and generate actionable business insights .
PROJECT OVERVIEW :

Sales 360 is an end to end Data Analytics project created to analyze sale data and generate meaningful business insights using Excel, SQL, and Power BI. This project covers the complete analytics workflow from data cleaning and preparation to SQL based analysis and interactive dashboard creation.

BUSINESS OBEJCTIVE:
The objective of this project is to understand sales performance ,customer behavior , product performance, payment status , and return and to identify useful insights that can support business decision making .

Tools & Technologies :
MICROSOFT EXCEL: Data cleaning,  data preparation, calculation and initial analysis.
SQL: Data analysis and answering business questions.
Power BI : Interactive dashboard, data modelling and data visualization .

DATASET : This project contains multiple tables related to :
CUSTOMERS
EMPLOYEES
PRODUCTS
ORDERS
PAYMENTS
RETURNS

EXCEL ANALYSIS:

PROCESS INCLUDED:
DATA CLEANING 
IDENTIFYING AND HANDLING ISSING VALUES
DATA VALIDATION
FORMATTING AND CHECKING DATA TYPES
PREPARING DATA FOR FURTHER SQL AND POWER BI ANALYSIS.

SQL ANALYSIS:

SQL was used to answer 15 business focused question related to sales performance, products, customers , categories ,payment and returns.

SQL Concept:

SELECT,WHERE,GROUP BY, HAVING, ORDER BY , AGGREGATE FUNCTIONS, JOINS ,SUBQUERIES WINDOWS FUNCTIONS.

This analysis basically focused on converting raw data into useful business insights .
